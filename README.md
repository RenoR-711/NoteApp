# Notiz-App (NoteApp)

Eine einfache Notiz-App, entwickelt in Kotlin im Rahmen einer Weiterbildung. Mit dieser App können Nutzer schnell und unkompliziert Notizen erstellen, bearbeiten und löschen.

## Funktionen

- Notizen erstellen, bearbeiten und löschen
- Übersichtliche Liste aller Notizen
- Speichern der Notizen lokal auf dem Gerät
- Einfaches und intuitives UI

## Technologie-Stack

- Programmiersprache: Kotlin
- Plattform: Android
- Architektur: MVVM (optional, je nachdem ob du das genutzt hast)
- Speicherung: SQLite / Room (oder SharedPreferences, je nach Implementierung)

## Nutzung

- Öffne die App.
- Tippe auf das Plus-Symbol, um eine neue Notiz zu erstellen.
- Schreibe deine Notiz und speichere sie.
- Um eine Notiz zu bearbeiten, tippe auf die Notiz in der Liste.
- Um eine Notiz zu löschen, wische die Notiz nach links/rechts (je nach Implementierung) oder nutze die Löschoption.
